# Industry CV LaTeX Draft

Files in this folder:

- `cv.tex`: self-contained LaTeX source for a 2-page, hiring-focused research scientist CV

Compile with:

```bash
pdflatex cv.tex
```

If you want a cleaner build flow:

```bash
latexmk -pdf cv.tex
```

This draft is intentionally optimized for research scientist roles in industry and national labs:

- concise summary
- impact-oriented experience bullets
- shortened education section with honors
- selected publications instead of a full academic bibliography
